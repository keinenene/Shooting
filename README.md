# STARFALL（仮題）

スマホのブラウザで遊ぶ縦画面の弾幕シューティング。外部ライブラリ・素材なし、ビルドなし。
仕様は [docs/spec.md](docs/spec.md) を参照。

## 現在の状態（M5）

1面を通しで遊べる：タイトル → 難易度選択 → 道中前半 → 中ボス → 道中後半 → ボス（4フェーズ）→ 結果。
タイトルから「練習」「設定」も開ける。ホーム画面に追加すると、オフラインでも起動できる（PWA）。

| 操作 | 内容 |
|---|---|
| 画面のどこでもドラッグ | 自機が指の移動量だけ動く（相対移動） |
| 左下「低速」を押している間 | 低速移動、判定点の表示、ショットを前方に集める（ボスへの火力が大きく上がる）、近くのアイテムを吸い寄せる |
| 左下「ボム」（低速の上） | 衝撃波で弾を消し（消えた弾はスコア点に）、触れた敵を倒し、ボスに届くとダメージ。発動中は無敵。被弾直後の赤い輪が縮み切る前に押すと喰らいボム |
| 右上「Ⅱ」 | ポーズ（再開／やり直す／タイトルへ）。再開は3秒数えてから。アプリが裏に回っても自動でポーズ |

練習モード
- 難易度ごとに、一度到達した区間（道中前半・中ボス・道中後半・ボス）とボスの各フェーズを選んで遊べる
- 2つ目の区間以降は攻撃力最大から始まる。ハイスコアには記録しない
- 「突破／挑戦」の回数を表示する（突破＝被弾せずに終えた回数）

設定：効果音・BGMの音量、移動感度（0.8〜1.6）、ボタン配置（左下／右下）、判定点の常時表示、画面振動

アイテム
- 赤い「P」：攻撃力アップ（小は+0.025倍、大は+0.125倍。1.0〜1.5倍）。ミスすると0.125倍下がり、一部がその場に散らばる
- 緑の「B」：ボム+1（中型機と中ボスが落とす。上限ならスコアに）
- 青い粒：スコア点（ボムやフェーズの削り切りで消えた弾が変わったもの。自動で集まる）
- 自機が画面の上から1/4より上に行くと、画面内のアイテムを全部吸い寄せる

音は最初に画面をタップしたときから鳴る（効果音と、道中・ボスのBGM）。
ハイスコアと区間・フェーズの記録は端末のブラウザに保存される。

ボス戦のルール（詳しくは仕様書4.3）
- ボスの体力はフェーズごとに25%ずつ。削り切るか、制限時間まで耐えれば次のフェーズへ
- 最後のフェーズは攻撃が効かない耐え切りフェーズ。生き残ればボスを撃破
- 削り切りは「素点＋残りタイムボーナス」、時間切れは素点のみ。ノーミス・ノーボムでボーナス
- 3つ目のフェーズでは、ボスが赤く光ったあと突進してくる（突進中だけ本体に当たり判定がある）

### デバッグ（`?debug=1` を付けて開く）
- タイトルに「パターンテスト」が出る（M2のテスト画面。基本12パターンと約1000発の負荷テスト）
- プレイ中に「次へ」（道中を飛ばす・ボスのフェーズを終える）「無敵」ボタンが出る

## 起動方法

ES Modules を使うので、ファイルを直接開くのではなく、HTTPサーバーから配信する。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## スマホ実機での確認

### GitHub Pages（推奨）
1. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にする
2. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開く

### 同じWi-Fi内でのローカル配信
1. PCで `python3 -m http.server 8000` を実行する
2. PCのIPアドレスを調べる（macOS: `ipconfig getifaddr en0`、Windows: `ipconfig`）
3. スマホで `http://<PCのIPアドレス>:8000/` を開く

### ホーム画面に追加（PWA）
GitHub Pages のURLをスマホで開き、共有メニュー（iPhone は Safari の共有ボタン）から「ホーム画面に追加」を選ぶ。
一度開いたあとはオフラインでも起動できる。

※ 更新を反映する仕組み：保存済みのファイルですぐ起動し、裏で最新版を取り直す。そのため **更新は次に開いたとき（再読み込みしたとき）に反映される**。
※ `src/` にファイルを追加したら、`sw.js` の `ASSETS` にも追加すること（オフラインで読めなくなるため）。

## ファイル構成

```
index.html             キャンバスとスクロール防止のCSS
src/config.js          調整用の定数（速度、判定、難易度係数など）
src/main.js            起動、固定ステップのゲームループ
src/view.js            画面の拡大縮小、座標変換
src/input.js           タッチ入力（相対ドラッグ、ボタン）
src/rng.js             シード付き乱数
src/ships.js           機体の定義（速さ、判定、ショット、攻撃力の伸び方）
src/player.js          自機
src/shots.js           自機ショット
src/bullets.js         敵弾（型付き配列のプール、判定、グレイズ、イベント）
src/emitter.js         パターン定義を読んで弾を撃つ
src/sprites.js         弾の見た目（起動時に一度だけ描く）
src/patterns/basic.js  基本12パターン（データのみ）
src/render.js          背景の星、パーティクル
src/debug.js           FPS計測、デバッグ用フラグ
src/ui.js              ボタン配置・描画などの共通部品
src/bomb.js            ボム（衝撃波）
src/boss.js            ボス・中ボス（フェーズ、体力の上限、移動、突進、時間切れで去る）
src/enemies.js         道中の敵（種類、軌道、ドロップ）
src/items.js           アイテム（攻撃力、ボム、スコア点）
src/audio.js           Web Audio の効果音と BGM（譜面データつき）
src/storage.js         localStorage（ハイスコア、区間・フェーズの記録、設定）
src/stages/stage1.js   1面のデータ（道中のタイムライン、敵の弾幕、中ボス、ボス）
src/scenes/game.js     ゲーム本編（タイトル、難易度選択、ステージ進行、HUD、結果、練習）
src/scenes/menus.js    練習モードと設定画面のボタン配置・描画
src/settings.js        設定の反映と保存
src/wakelock.js        プレイ中に画面が暗くならないようにする
manifest.json, sw.js   PWA（ホーム画面への追加、オフライン動作）
icons/                 アプリのアイコン
src/scenes/test.js     パターンテスト画面（?debug=1）
```

## 弾パターンの足し方

`src/patterns/basic.js` の配列にオブジェクトを足すだけで増やせる。角度は度（0度が右、90度が真下）、速さは px/フレーム。

```js
{
  id: 'my_pattern', name: '新しいパターン',
  emitters: [{
    interval: 6, count: 5, spread: 360,
    baseAngle: { type: 'rotate', start: 0, speed: 4 },  // fixed / rotate / sine / aim / random
    bullet: {
      type: 'rice', color: '#4df', speed: 3, accel: -0.05, minSpeed: 0,
      events: [{ at: 60, do: 'aim', accel: 0.05, maxSpeed: 3 }],  // stop / aim / turn / split / vanish
    },
  }],
}
```
